Lab Overview

What you will accomplish

IBM Bob is an agentic integrated development environment (IDE) that helps you write, test, upgrade, and secure software across the entire software development lifecycle (SDLC). In this tutorial series you work with the Galaxium Travels demo application.

About Galaxium Travels

Galaxium Travels is a fictional luxury interplanetary space travel booking system built as a realistic, intentionally complex demo application. It features a React + TypeScript frontend, a Python FastAPI backend with both REST and MCP interfaces, and a Java Spring Boot inventory hold service — all backed by SQLite. Its multi-language, multi-service architecture makes it an ideal target for demonstrating Bob's agentic capabilities across the full software development lifecycle.

Project Setup

Give Bob persistent context with /init and AGENTS.md so it understands your project on every conversation.

Codebase Inspection

Rapidly understand an unfamiliar application — purpose, architecture, tech stack, test coverage, and deployment model.

Architecture Diagrams

Generate UML class diagrams, sequence diagrams, and use case diagrams from source code using Mermaid.

Security Audit

Create a reusable OWASP ASVS audit skill, scan the codebase, and generate SARIF and OSCAL remediation reports.

Plan & Implement

Use Plan mode to scope and review a feature plan before Bob writes any code — then implement with Agent mode.

App Modernization

Upgrade a Node.js Express API from v16 to v22 using Bob's modes, approvals, and literate coding.

The Modernize Node.js tutorial uses a separate repo:

bash

Open the project in Bob IDE

  • Open Bob IDE.
  • Select File → Open Folder and choose the cloned directory.
  • If Bob asks "Do you trust the authors?", click Yes, I trust the authors.
  • Open the Bob chat interface: click the Bob icon in the navigation bar, or press ⌥⌘B (Mac) / Ctrl+Alt+B (Windows).
Auto-approval

Several tutorials ask you to turn off auto-approval so Bob requests your permission before executing each step. You can find this setting under Permissions in the chat panel.

Demo Application

Architecture of Galaxium Travels

Galaxium Travels is a fictional luxury space travel booking system with a multi-service, full-stack architecture. Its intentional complexity — spanning three services in three languages — makes it a strong candidate for AI-assisted analysis.

LayerTechnologyKey files
Front endReact, TypeScriptbooking_system_frontend/
Back end (REST + MCP)Python, FastAPIbooking_system_backend/server.py
Inventory hold serviceJava, Spring Bootbooking_system_inventory_hold_service/
DatabaseSQLite with seed databooking_system_backend/models.py
End-to-end testsPlaywright (or similar)tests_e2e/
InfrastructureDocker Compose, Terraform, GitHub Actionsdocker-compose.yml, terraform/, .github/workflows/

Three services, three languages

React/TypeScript frontend → Python FastAPI backend → Java Spring Boot inventory hold service. Bob must reason across all three service boundaries during tutorials.

MCP interface

The Python backend exposes both a standard REST API and an MCP (Model Context Protocol) interface, which lets Bob interact directly with the back end as a tool during agentic tasks.
