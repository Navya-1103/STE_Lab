Lab Overview

What you will accomplish

IBM Bob is an agentic integrated development environment (IDE) that helps you write, test, upgrade, and secure software across the entire software development lifecycle (SDLC). In this tutorial series, you use Bob to add features to the Galaxium Travels demo application.

Project Setup

Set up Bob in the Galaxium Travels repository and give Bob persistent context with /init and AGENTS.md files.

Standardize Behavior

Standardize Bob's behavior with custom rules files and create a custom mode to help with product management tasks.

AI-Assisted Coding

Write code with Bob's AI-assisted code completion features and use literate coding to generate code from written text.

Agentic Workflows

Use Bob's agentic capabilities to have Bob run prompts and perform actions, including Git commits and pull requests.

Context Management

Understand how to manage the context window effectively to maintain output quality and reduce token cost.

Version Control

Use Bob's native Git integration to create branches, stage changes, commit, push, and open pull requests.

Prerequisites

Getting Started

Before starting the tutorials, make sure you have the following tools installed and the Galaxium Travels demo repository cloned.

Step 1 — Download and install IBM Bob IDE

Bob is a standalone IDE application — not a plugin or extension. Download and install it from the official site.

Download Bob IDE ↗

Step 2 — Clone the Galaxium Travels demo repository

The clone command also checks out the bob-learning-path-branch that contains the code you use in the tutorials.

bash
git clone -b bob-learning-path-branch https://github.com/IBM/galaxium-travels

Step 3 — Open the project in Bob IDE

  • Open Bob IDE.
  • Select File → Open Folder.
  • Choose the galaxium-travels directory you cloned.
  • Wait for the project tree to load.
Tip

While not required, consider doing the Quickstart tutorial to familiarize yourself with Bob's interface and features before starting this series.

Demo Application

Architecture of Galaxium Travels

Galaxium Travels is a fictional luxury space travel booking system with a full-stack architecture. You will use this application throughout the tutorial series.

Layer Technology
Front endReact, TypeScript
Back endPython with REST and MCP interfaces
DatabaseSQLite with seed data

Front End

The React/TypeScript front end connects to back-end REST endpoints and presents data through a user-facing interface. Features include: viewing available flights, user registration and authentication, and flight booking.

Back End

Built around a SQLite database with data models, schemas, and seed data. Exposes a REST API for front-end consumption and an MCP interface that lets Bob interact directly with the back end as a tool.

Did you know?

An API browser interface is available locally to explore and interact with back-end endpoints directly, without the front end. This lets you test operations such as flight retrieval, user registration, and booking.
