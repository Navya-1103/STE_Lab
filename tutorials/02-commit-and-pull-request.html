Tutorial 02 · Version Control

Create a commit and pull request with Bob

Use Bob to create a branch, stage changes, generate a commit message, push to your repository, and open a pull request.

Prerequisites

What you need

  • IBM Bob IDE — Download and install the IBM Bob application. Bob is a standalone IDE application, not an extension.
  • Git — Install Git to clone the example repository.
  • GitHub account — A GitHub account and a fork of the Galaxium Travels example repository.
  • GitHub SSH authentication — Generate an SSH key and add it to the ssh-agent so you can push to your fork over SSH.
Step 01

Set up the project

Fork the repository

You will work from a fork of the Galaxium Travels repository.

  1. Go to the Galaxium Travels repository on GitHub.
  2. Click the Fork button in the top-right corner of the page.
  3. Select your GitHub account as the owner of the fork.

Clone the repository

In a terminal, clone the forked Galaxium Travels repository. Replace <YOUR_ID> with your GitHub username:

bash
git clone git@github.com:<YOUR_ID>/galaxium-travels.git
Authentication

If you get an authentication error, ensure you have added your SSH key to the ssh-agent. See GitHub's SSH documentation for more information.

  1. In Bob, click File then Open Folder.
  2. Navigate to the galaxium-travels directory you just cloned and open it.
Step 02

Switch to Agent mode

If the Bob chat interface is not already opened, open it by clicking the Bob icon beside the navigation bar or use the shortcut Option + Command + B (Mac) or Ctrl + Alt + B (Windows).

Use Agent mode so Bob can write and modify code, run Git commands, and guide you through the workflow. Bob still asks for permission before each operation unless explicitly allowed.

Click the mode selector drop-down in the agentic chat and select Agent, or type /agent in the chat.

Step 03

Create a branch

Before making changes, create a feature branch so your work stays separate from main.

bob prompt
Create and switch to a new branch named update-header.

Bob requests permission to run git checkout -b update-header. Click Approve for task to create the branch and switch to it.

Step 04

Make a code change

Make a small change to give Bob something to commit.

Open the Header component

In the Galaxium Travels codebase, open booking_system_frontend/src/components/layout/Header.tsx.

Edit the header text

Ask Bob to make the change Galaxium Travels → Galaxium Travel Agency. The @ prefix adds a file to Bob's context so it knows exactly which file to edit.

bob prompt
Change the name of the Header from `Galaxium Travels` to `Galaxium Travel Agency` in @booking_system_frontend/src/components/layout/Header.tsx

Alternatively, you can manually edit the file and change the span to:

tsx
<span className="text-2xl font-bold bg-cosmic-gradient bg-clip-text text-transparent"> Galaxium Travel Agency </span>
Step 05

Run the Git workflow

Stage your changes

bob prompt
Stage all the changes I made for the header component update.

Bob inspects the working tree, identifies modified files, and requests permission to run git add. Click Approve for task.

Commit your changes

bob prompt
Commit the staged changes with a descriptive commit message that summarizes what was added.

Bob reviews the staged diff and generates a commit message. Click I understand the risks, then click Approve so Bob can run git commit.

Push the changes

bob prompt
Push my changes to the remote repository.

Bob identifies the current branch and remote, then requests permission to run git push. Click Approve for task.

Open a pull request

bob prompt
Create a pull request to merge my changes into the main branch. Write a clear title and description based on what was changed.

Bob requires GitHub authentication the first time you create a pull request. Bob opens a browser window for you to authorize access. Once authorized, Bob opens the pull request. Click the provided link to access the pull request in your browser. After reviewing the title and description, click Create pull request.

Tip

To have Bob create pull requests without a confirmation window, install the GitHub CLI and ask Bob to use it to create pull requests.

Troubleshooting

Common issues

  • Push rejected or authentication failed: Confirm Git is configured with credentials that can push to your fork.
  • Branch update-header already exists: Ask Bob to switch to the existing branch or choose another branch name.
  • Pull request targets IBM/galaxium-travels: Change the base repository to your fork before creating the pull request.
Summary

Next steps

In this tutorial, you learned how to use Bob's native Git integration to manage code changes without leaving the IDE — including branching, staging, committing, pushing, and opening pull requests.
