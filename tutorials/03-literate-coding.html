Tutorial 03 · In-Editor AI

Use literate coding to generate code from comments

Use literate coding to have Bob generate code from natural language comments. Bob helps you write precise, context-aware code modifications directly in your editor.

Overview

What is literate coding?

Literate coding lets you write code with AI assistance directly inside your editor. Instead of switching to a chat window or writing long prompts, you type instructions in plain language right where the code should go. Bob then generates the implementation for you in context and shows a diff of the changes.

Literate coding is most effective for the following types of modifications:

  • Adding wrapper logic: Retry mechanisms, error handling, or logging around existing code.
  • Refactoring specific blocks: Modifying targeted sections while preserving surrounding logic.
  • Quick targeted modifications: Precise changes to specific functions without affecting broader structure.
Tip

For complex modifications that affect multiple functions or files, consider using the Hi, I'm Bob agentic chat interface to create a Plan instead of literate coding.

The scenario

In this tutorial, you fix an intermittent timeout by wrapping a code block with retry logic. The Galaxium Travels back end is unreliable and occasionally gets timeout errors. Instead of rewriting the code from scratch, you use literate coding to wrap the specific block of code with retry logic.

Prerequisites

What you need

  • Clone the Galaxium Travels demo code:
bash
git clone -b bob-learning-path-branch https://github.com/IBM/galaxium-travels
  • IBM Bob IDE open with the Galaxium Travels project loaded.
  • You have run /init in the Bob agentic chat interface. Refer to Tutorial 01 if you have not done this yet.
  • You may want to start a new context window for this tutorial. Refer to Tutorial 06 for instructions.
Step 01

Open the file

Open the following file in Bob IDE:

path
booking_system_frontend/src/pages/Flights.tsx
Step 02

Position your cursor

Click into line 43 in the file. This is the location where Bob will insert the retry logic.

Step 03

Activate literate coding mode

Click the ellipsis (…) menu in the editor toolbar and then select Literate Coding Mode.

Step 04

Write your instruction

Enter the following natural language instruction to describe the desired change on line 43:

literate coding instruction
The backend is unreliable at times. We need a retry logic here
Step 05

Generate and accept the changes

Generate the code

Click Generate to produce the modifications. Bob presents changes in a diff view interface. The highlighted red text shows what code is removed and the highlighted green text shows what code Bob adds.

Accept the changes

Review the changes and click Accept All to apply them.

Result

You have added a retry loop to resolve timeout errors in the Galaxium Travels web application. The change was applied in-editor with a clear diff — no chat switching required.
